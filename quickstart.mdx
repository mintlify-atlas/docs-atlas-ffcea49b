## One command setup

Get started with cc-statusline in three simple steps:

<Steps>
  <Step title="Run the installer">
    Execute the interactive installer:
    
    ```bash
    npx @chongdashu/cc-statusline@latest init
    ```
    
    <Info>
      This command works immediately without any global installation. The `@latest` tag ensures you get the newest version.
    </Info>
  </Step>
  
  <Step title="Answer the prompts">
    The installer will ask two questions:
    
    **1. Installation location:**
    ```bash
    ? Where would you like to install the statusline?
    ❯ Project-level (.claude/ in current directory)
      Global (~/.claude/ in home directory)
    ```
    
    **2. Feature selection:**
    ```bash
    ? Select the features you want to include:
    ◉ Directory display
    ◉ Git branch
    ◉ Model name & Claude Code version
    ◉ Output style
    ◉ Context usage (requires jq)
    ◉ Cost & burn rate
    ◯ Session reset time (requires ccusage)
    ◉ Token statistics
    ```
    
    <Tip>
      All features are pre-selected except session reset time. Use **Space** to toggle, **Enter** to confirm.
    </Tip>
  </Step>
  
  <Step title="Restart Claude Code">
    Close and reopen Claude Code to see your new statusline:
    
    ```bash
    📁 ~/my-project  🌿 main  🤖 Sonnet 4  📟 v1.0.85  🎨 default
    🧠 Context Remaining: 95% [=========-]
    💰 $2.48 ($12.50/h)  📊 485234 tok (8420 tpm)
    ```
    
    <Warning>
      The statusline won't appear until you restart Claude Code.
    </Warning>
  </Step>
</Steps>


## Understanding your statusline

Here's what each element means:

### Line 1: Environment information

```bash
📁 ~/my-project  🌿 main  🤖 Sonnet 4  📟 v1.0.85  🎨 default
```

<AccordionGroup>
  <Accordion title="📁 Directory display">
    Shows your current working directory with `~` abbreviation:
    - `~/my-project` - Project in home directory
    - `~/code/work/api` - Nested project path
    - `/usr/local/bin` - Absolute paths shown as-is
  </Accordion>
  
  <Accordion title="🌿 Git branch">
    Displays the current git branch:
    - `main` - Default branch
    - `feature/statusline` - Feature branch
    - Empty if not in a git repository
  </Accordion>
  
  <Accordion title="🤖 Model name">
    Shows which Claude model is active:
    - `Sonnet 4` - Claude 4.5 Sonnet
    - `Opus 3` - Claude 3 Opus
    - `Haiku 3` - Claude 3 Haiku
  </Accordion>
  
  <Accordion title="📟 Claude Code version">
    Displays your Claude Code version:
    - `v1.0.85` - Release version
    - Helps track compatibility
  </Accordion>
  
  <Accordion title="🎨 Output style">
    Shows the current output style setting:
    - `default` - Standard output
    - `XML` - XML-formatted responses
    - `JSON` - JSON-formatted responses
  </Accordion>
</AccordionGroup>

### Line 2: Context and session tracking

```bash
🧠 Context Remaining: 83% [========--]  ⌛ 3h 7m until reset at 01:00 (37%) [===-------]
```

<AccordionGroup>
  <Accordion title="🧠 Context remaining">
    Shows how much of your context window is available:
    - `95% [=========-]` - Plenty of room
    - `50% [=====-----]` - Half used
    - `10% [=---------]` - Almost full (consider starting fresh)
    
    <Note>
      Requires `jq` to be installed. Without jq, this feature won't display.
    </Note>
  </Accordion>
  
  <Accordion title="⌛ Session timer">
    Countdown to when your usage limits reset:
    - `3h 7m until reset at 01:00` - Time remaining
    - `(37%) [===-------]` - Progress bar showing elapsed time
    - Helps you plan when to start resource-intensive tasks
    
    <Warning>
      Requires `ccusage` and is the only feature that needs this external tool.
    </Warning>
  </Accordion>
</AccordionGroup>

### Line 3: Cost and token analytics

```bash
💰 $49.00 ($16.55/h)  📊 14638846 tok (279900 tpm)
```

<AccordionGroup>
  <Accordion title="💰 Cost tracking">
    Displays your current session costs:
    - `$49.00` - Total cost so far
    - `($16.55/h)` - Burn rate (cost per hour)
    - Helps you stay within budget
    
    <Tip>
      The burn rate is calculated from Claude Code's native cost and duration data - no external tools needed!
    </Tip>
  </Accordion>
  
  <Accordion title="📊 Token statistics">
    Shows token consumption metrics:
    - `14638846 tok` - Total tokens used (input + output)
    - `(279900 tpm)` - Tokens per minute burn rate
    - Uses Claude Code's native `context_window` data
    
    <Info>
      As of v1.4.0, token stats are calculated natively from Claude Code's JSON input - no ccusage needed!
    </Info>
  </Accordion>
</AccordionGroup>

## Common first-time issues

<AccordionGroup>
  <Accordion title="Statusline not showing after restart">
    **Problem:** Claude Code started but no statusline appears.
    
    **Solutions:**
    
    <Steps>
      <Step title="Check settings.json">
        Verify the configuration exists:
        
        ```bash
        cat .claude/settings.json
        ```
        
        Should contain:
        ```json
        {
          "statusLine": {
            "type": "command",
            "command": ".claude/statusline.sh",
            "padding": 0
          }
        }
        ```
      </Step>
      
      <Step title="Check permissions">
        Ensure the script is executable:
        
        ```bash
        ls -l .claude/statusline.sh
        ```
        
        Should show: `-rwxr-xr-x` (note the `x` for executable)
        
        If not, fix it:
        ```bash
        chmod +x .claude/statusline.sh
        ```
      </Step>
      
      <Step title="Test manually">
        Run the script directly:
        
        ```bash
        echo '{}' | .claude/statusline.sh
        ```
        
        This should output your statusline (with some missing data due to empty JSON).
      </Step>
    </Steps>
  </Accordion>
  
  <Accordion title="Missing jq warning">
    **Problem:** Installer warns that jq is not installed.
    
    **Impact:**
    - No context remaining percentage
    - No token statistics
    - No session timer
    - Basic fallback parser used (less reliable)
    
    **Solution:**
    
    <Tabs>
      <Tab title="macOS">
        ```bash
        brew install jq
        ```
      </Tab>
      <Tab title="Linux">
        ```bash Ubuntu/Debian
        sudo apt-get install jq
        ```
      </Tab>
      <Tab title="Windows">
        ```powershell
        # Using Chocolatey
        choco install jq
        
        # Or Scoop
        scoop install jq
        ```
      </Tab>
    </Tabs>
    
    After installing jq, re-run the installer:
    ```bash
    npx @chongdashu/cc-statusline@latest init
    ```
  </Accordion>
  
  <Accordion title="Slow execution (> 500ms)">
    **Problem:** Statusline takes a long time to display.
    
    **Solutions:**
    
    1. **Check performance:**
       ```bash
       cc-statusline preview .claude/statusline.sh
       ```
       Look for the execution time in the output.
    
    2. **Disable heavy features:**
       Re-run init and disable session timer (requires external ccusage call):
       ```bash
       npx @chongdashu/cc-statusline@latest init
       ```
    
    3. **Check for stale processes:**
       ```bash
       ps aux | grep ccusage | grep -v grep
       ```
       Kill any hanging processes if found.
  </Accordion>
  
  <Accordion title="Colors not working">
    **Problem:** Statusline shows without colors or with garbled characters.
    
    **Causes:**
    - `NO_COLOR` environment variable is set
    - Terminal doesn't support 256 colors
    - Using a non-standard terminal
    
    **Solutions:**
    
    1. **Check NO_COLOR:**
       ```bash
       echo $NO_COLOR
       ```
       If it outputs anything, unset it:
       ```bash
       unset NO_COLOR
       ```
    
    2. **Verify terminal color support:**
       ```bash
       echo $TERM
       ```
       Should be `xterm-256color` or similar.
  </Accordion>
</AccordionGroup>

## Tips for best experience

<Tip>
  **Enable all features** - Unless you're experiencing performance issues, keep all features enabled for maximum visibility.
</Tip>

<Tip>
  **Install jq** - The advanced features are worth it. Install jq for the full experience.
</Tip>

<Tip>
  **Use preview frequently** - Test changes with `cc-statusline preview` before restarting Claude Code.
</Tip>

<Tip>
  **Monitor burn rate** - Keep an eye on the `$/h` metric to stay within your budget.
</Tip>

<Tip>
  **Watch context usage** - When it drops below 20%, consider starting a fresh session for better responses.
</Tip>
